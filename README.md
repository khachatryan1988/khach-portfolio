# Portfolio Website

Personal portfolio website for **Python Backend Developer**.  
Inspired by LinkedIn profile, focused on clarity, structure, and engineering mindset.

## 
- Hero section with backend positioning
- Experience timeline (LinkedIn-style)
- Skills grouped by backend categories
- Projects section with Swagger previews
- Download CV
- OpenGraph & social preview
- Dark premium UI

##  Tech Stack
- Python 3.12
- FastAPI
- Jinja2
- Tailwind CSS (CDN)
- Docker & Docker Compose

## Run locally
```bash
docker compose up --build
